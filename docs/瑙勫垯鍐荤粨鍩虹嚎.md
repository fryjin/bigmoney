# 规则冻结基线

本文件只声明规则来源和冻结原则，不重复完整规则全文。

## 来源

以 2026-08-05 当日确认的以下设计为唯一规则基线：

- 2～4名玩家，同设备本地多人；
- 36格单向、单路径闭环地图；
- 单个D6，每个正常回合必须投骰；
- 地产购买、三级升级、租金、50%清算与破产淘汰；
- 免费随机抽卡、手牌上限3、攻击与单次防御响应；
- 股票市场路径触发、固定投资档、2/4/6大轮周期；
- 随机事件、合作项目、小游戏、监狱、公共设施；
- 最后一名未破产玩家获胜；
- 初始资金5000万元，过终点800万元；
- 游戏内部最小金额单位为10万元。

## 冻结要求

开发阶段不得以“实现方便”“体验可能更好”为理由自行修改规则。发现冲突或缺口时：

1. 记录具体场景；
2. 保持现有实现不扩展；
3. 提交产品确认；
4. 经确认后更新规则版本与迁移说明。
