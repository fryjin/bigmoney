# Big Money 第一阶段设计与技术协作任务清单

## 目标

用一个 8 节点正式质量切片验证：

- Phaser 场景能力；
- XState 中断与恢复；
- Vue HUD 与 Context Panel；
- 2.5D 城市资产质量；
- iPad 触控与性能；
- 规则层和表现层分离。

## 合并门槛

- 规则代码不引用 Phaser/Vue。
- Vue 不直接修改 GameState。
- Phaser 动画不计算金币和租金。
- 设计资产具有正式质量，不使用通用几何楼占位。
- Cloudflare 预览可在真实 iPad 横屏运行。
- 截图与录屏经过设计验收。
